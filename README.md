# Friendpocalypse

Кооператив на 1–8 игроков. [Скачать Windows-лаунчер](https://github.com/kavotavochavo1-ctrl/friendpocalypse/releases).

Запусти Steam и лаунчер. Хост создаёт комнату, друзья вводят FP-код и нажимают «Я готов!», хост запускает забег. Можно пригласить через встроенный список друзей Steam. Соло и боты работают без Steam. Исходный браузерный режим сохраняется и использует Trystero.

Для автообновлений устанавливай **Setup.exe**. Проверка запускается при открытии лаунчера; скачивание и установка происходят по кнопке. ZIP предназначен для ручного обновления. Настройки и сохранения хранятся в профиле пользователя, вне папки установки.

AppID **480** — тест для друзей. Steam показывает Spacewar. Приглашения поддерживаются, пока этот лаунчер запущен у получателя. Для автоматического запуска именно нашей игры через Steam нужен собственный AppID. Встроенное приглашение работает без оверлея. При выходе хоста создайте новую комнату.

## Сборка Windows x64

Node.js 24, Windows:

```powershell
npm ci --ignore-scripts
node tools/fetch-steam.cjs
npm test
npm run dist:win
```

Результат в `release/`: установщик, ZIP, `latest.yml`, `.blockmap`. Для разработки: `npx install-electron --no`, затем `npm start`.

`fetch-steam.cjs` получает только redistributable DLL по закреплённому Git-коммиту, проверяет SHA256 и подпись Valve. Остальной SDK не распространяется. При наличии собственного SDK можно заранее положить эту же проверенную DLL по пути `vendor/steamworks_sdk/redistributable_bin/win64/steam_api64.dll`.

## Следующий релиз

Измени версию в `package.json` и lockfile, обнови `RELEASE_NOTES.md`, создай тег `vX.Y.Z`. GitHub Actions соберёт и опубликует файлы. Для автообновления в одном **обычном, не prerelease** релизе должны находиться установщик, `latest.yml` и `.blockmap` с исходными именами. Релизы 0.1.0–0.1.3 опубликованы после локальной сборки и проверки.

Для собственного Steam AppID: замени 480 в `desktop/main.cjs` и `desktop/steam_appid.txt`, настрой запуск exe в Steamworks. Сертификат Windows для подписи установщика настраивается отдельно через electron-builder.

Сетевой адаптер: `desktop/steam-net.cjs`; изолированный мост: `desktop/preload.cjs`; поддержка существующего room API: `steam-room.js`. Данные лобби проверяются по `game=friendpocalypse` и `protocol=steam-3`. Код FP — точное представление ID лобби; чужие лобби Spacewar отклоняются. Соединения принимаются только от участников текущего лобби.
